# RepeatLab Landing Page

This is the landing page for RepeatLab, built with Astro and TailwindCSS.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview the production build:
```bash
npm run preview
```
