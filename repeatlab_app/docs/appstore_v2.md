## ASO notes (not part of the listing text)

### Keywords woven into the description

Google Play indexes the long description, so high-intent search phrases are placed naturally in the copy (Apple does not index the description — see keyword field below):

- "loop audio", "loop video", "looper for musicians"
- "slow down music", "slow downer", "change speed", "without changing pitch"
- "practice", "play along", "tutorials", "by ear", "transcribing"
- instrument terms: guitar(ists), singers, drummers, bass, piano
- "BPM", "MP3", "WAV", "MP4", "offline"

### Apple-specific fields (description is NOT indexed on iOS)

- **Title (30 chars):** `RepeatLab: Audio Video Looper`
- **Subtitle (30 chars):** `Slow Down Music & Loop Songs` — highest-impact ASO field after the title; carries "slow down music" which the title can't fit.
- **Keyword field (100 chars, no spaces after commas, don't repeat title/subtitle words):**
  `practice,guitar,tabs,bpm,tempo,pitch,trainer,transcribe,riff,solo,rehearsal,speed,player,ear`
- **Promotional text (170 chars, updatable without review):**
  `NEW: Video looping is here! Import tutorials or live videos, loop any section, and slow it down — practice along at your own pace.`

### Rationale for the main changes

1. **Video is the headline.** It's the differentiator vs. Anytune, Amazing Slow Downer & co. — it leads the title, gets its own "NEW" block, and adds video-intent keywords (tutorials, dancers, choreography).
2. **"Slow down music" moved up.** It's the highest-volume search intent for this category; the old copy buried it as "variable speed playback."
3. **Benefit-led "Perfect for" list.** "Guitarists learning solos" indexes more long-tail phrases than "Guitar players" and shows the use case.
4. **Added a "How it works" sequence.** Conversion element — visitors who read past the features see the core workflow in 4 lines.
5. **Newer features surfaced:** loop export (MP3/WAV), full library backup/restore, drag-and-drop sorting, waveform zoom, 16 languages.
6. **Honest claims only:** pitch is *preserved* during speed changes (no pitch-shifter claim); video format list trimmed to the recognizable ones ("and more" covers M4V/MKV/WebM).

### Open points

- Video is still flagged Beta in-app — the proposal markets it without the beta label, since store visitors don't benefit from that caveat. If you prefer caution, append "(Beta)" to the NEW block headline.
- Prices kept as currently listed (€0.99 / €5.99 / €19.99). If the repricing from `docs/potential.md` lands together with the video launch, update this block in the same release.
- Consider refreshing screenshots/preview video to show video looping — on iOS, visuals drive more conversion than the description.
